🧺 Weekly Basket Admin

Make free-access codes for yourself, testers, affiliates and gifts. Everything happens in this browser: your admin key is never uploaded or saved.

1. Open your admin key

The file weekly-basket-admin-key.json. Keep it private: anyone who has it can make free codes.

2. Make a code

Users see it as "Free access (name)". For affiliates, use the name their followers know.

After this day new people can't use it. People who already used it keep their free days.

Switch a code off

Codes can't be deleted remotely (there is no server). Add the code's id to MP.REVOKED_CODES in js/access.js; it stops working once the app is updated.

Make a new admin key (only if yours is lost or leaked)

A new key makes every old code stop working once the app is updated with the new public key.
